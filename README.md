# Robot Cell Optimizer

Automated industrial robot-cell analysis and optimization platform built with ROS 2, MoveIt 2 and C++.

## Planned capabilities

- Cartesian target reachability
- inverse kinematics analysis
- joint-limit analysis
- manipulability and singularity detection
- collision checking
- motion planning
- cycle-time estimation
- robot-base placement optimization

## Initial milestone

Given a set of Cartesian target poses, determine which targets are reachable by a simulated industrial robot.

## Stack

- ROS 2 Jazzy
- MoveIt 2
- C++
- Eigen
- OMPL
- Gazebo Harmonic
